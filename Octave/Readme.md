# Generating Filter Coefficients

The scripts below are used in [GNU Octave][GNU Octave] which should be available
on most platforms including Linux, Mac and Windows.

On Debian and other Debian derived Linux distributions, Octave can be installed
using: `sudo apt install octave octave-signal`.

## Generating the coefficient tables

The coefficient tables of the three sinc converters (`src/fastest_coeffs.h`,
`src/mid_qual_coeffs.h` and `src/high_qual_coeffs.h`) are generated by running
the `octave` command in the same directory as the scripts and this Readme file:

```
octave:1> generate_tables
fastest_coeffs.h         :   9064 +   1632 coefficients, gain 0.83147237295483134
mid_qual_coeffs.h        :  15836 +   3536 coefficients, gain 0.91906323498616627
high_qual_coeffs.h       :  40720 +  10064 coefficients, gain 0.96572842353927779
```

`generate_tables.m` holds the parameters of the three filters and calls
`make_sinc_table.m` for each of them. This does not need the signal package.

Each filter is a Kaiser windowed sinc function, described by the increment and
half length it was designed with, the half length of the Kaiser window, the
fudge factor by which the sinc function is stretched and the stop band
attenuation the window is made for. `make_sinc_table.m` samples the filter at
64 points per input sample and writes the header file. The converters evaluate
the filter between these points using 4 point Lagrange interpolation. See the
comment at the top of `make_sinc_table.m` for the layout of the tables.

Up to version 0.2.2 the tables were made for linear interpolation instead and
held `increment` points per input sample (2381 for the best quality converter,
i.e. 340239 coefficients). The parameters in `generate_tables.m` were recovered
from those tables and reproduce their coefficients to within 1e-13.

## Designing a filter

A new filter can be designed as follows:

```
octave:1> pkg load signal
octave:2> f = make_filter (8, 128, 100.3) ;
# f = make_fip_filter (8, 128, 100.3) ;
#   Coeff. count     : 4922
#   Fudge factor     : 1.2018769
#   Pass band width  : 0.0039062499 (should be 0.0039062500)
#   Stop band atten. : 100.71 dB
#   -3dB band Width  : 0.490
#   half length      : 2464
#   increment        : 128
```

`make_filter.m` searches for the fudge factor that puts the start of the stop
band at half the sample rate. The result can then be passed on to
`make_sinc_table.m`. For the filter above (with `Coeff. count` N, the window
half length is `(N - 1) / 2`):

```
octave:3> make_sinc_table ("fastest_coeffs", 128, 2460, 2460.5, 1.2018769, 100.3, "fastest_coeffs.h") ;
```

Note that the parameters above are close to, but not exactly, the ones of the
filter in `src/fastest_coeffs.h`, which was made with an earlier version of
these scripts.
